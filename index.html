Veter Language syntax guide

Examples based on the current project direction. The browser preview supports only the core examples marked below; other features may need the native compiler and may still be experimental.

01 · Create or change a variable Compiler syntax

make score 10
set score score + 5
say score

Use make to create a variable and set to update one.

02 · Show output

say "Hello, Veter!"
show 12 + 5
print "Done"

say, show and print are output commands. Use a space after the command.

03 · Arithmetic

make a 20
make b 6
say a + b
say a - b
say a * b
say a / b
say a % b
say (a + b) * 2

Supports +, -, *, /, %, parentheses and normal arithmetic precedence.

04 · Read user input

take name
say name

take stores a line of user input in the named variable. Browser preview may not support interactive input.

05 · If / otherwise

make score 75
check score >= 50
  say "Pass"
otherwise
  say "Try again"
finish

Use check with ==, !=, <, <=, > or >=. Close the block with finish.

06 · Repeat loop

repeat 3 times
  say "Hello!"
end repeat

Repeats the enclosed statements the requested number of times.

07 · While-style loop

make count 1
keep count <= 3
  say count
  set count count + 1
end

keep repeats while its comparison stays true. The compiler uses end to close this loop.

08 · Functions

do greet
  say "Hello!"
end
run greet

Function form supported by the compiler: define with do name and call with run name. Close the function using end.

09 · Logic and comments

# This is a comment
check score >= 50 and score < 100
  say "In range"
finish

Use # for comments and and/or/not in supported conditions.

10 · String length

make word "Veter"
say len(word)

len(...) is supported in the compiler's expression syntax.
