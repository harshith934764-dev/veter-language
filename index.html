The idea

Designed to grow.
Built one layer at a time.

Veter is being developed as its own language project. The goal is a reliable core first, then better tools and AI-assisted workflows—without pretending unfinished features already exist.

Roadmap

From prototype to a real language.

Progress will be published honestly as each milestone is implemented and tested.

01 · Current

Feature prototype

Basic values, input/output, arithmetic, conditions, loops, and a website-builder prototype in the existing codebase.

02 · Next

Independent front end

Build a lexer and parser that understand Veter source directly, with clear syntax errors.

03 · Then

Runtime & tests

Implement and test types, scope, functions, control flow, and predictable runtime behavior.

04 · Later

Public release

Publish a stable release after installation, documentation, examples, and regression tests are reliable.
