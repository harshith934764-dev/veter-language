Veter Language syntax guide

Examples based on the current project direction. The browser preview supports only the core examples marked below; other features may need the native compiler and may still be experimental.

01 · Print text Preview supported

print("Hello from Veter!")

Use print() to display a value or message.

02 · Variables Preview supported

name = "Harshith"
age = 23
print(name)
print(age)

Assign a value to a variable with =.

03 · Arithmetic Preview supported

a = 20
b = 6
print(a + b)
print(a - b)
print(a * b)
print(a / b)
print(a % b)

Operators: + addition, - subtraction, * multiplication, / division, % remainder.

04 · Order of operations Preview supported

a = 10
b = 8
print(a + b * 2)
print((a + b) * 2)

Multiplication happens before addition; parentheses group expressions.

05 · Comments Preview supported

# This is a comment
print("Comments explain code")

Use # for a comment line.

06 · Comparisons Experimental

# Planned / experimental example
# if score >= 50 {
#     print("Pass")
# }

Comparison and conditional syntax must be verified against your compiler version before relying on it.

07 · Conditions Experimental

# Example concept — confirm syntax
# if ready {
#     print("Go!")
# } else {
#     print("Wait")
# }

Conditional blocks are part of the language roadmap; exact working syntax may vary by build.

08 · Loops and functions Roadmap

# Planned examples
# repeat 3 {
#     print("Hello")
# }
# fun greet() { ... }

Use these as design ideas only, not guaranteed runnable syntax.
